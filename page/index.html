Abstract

A benchmark for assistant agents that must notice what users leave unsaid

Pi-Bench studies long-horizon personal assistance in persistent workspaces. Each episode begins from a natural underspecified user request; the agent must recover latent preferences, dependencies, and constraints from history, ask targeted follow-up questions when needed, use tools, and deliver verifiable artifacts.

Hidden-intent driven

Tasks contain private requirements that users may reveal only after suitable agent behavior, making proactivity measurable rather than rhetorical.

Persistent personal context

Profiles, episodes, notes, files, tools, and prior sessions define realistic dependencies that agents must reuse across turns and tasks.

Separated evaluation

Proc measures proactive intent resolution; Comp measures checklist completion over the trajectory and final artifacts.

Method / Benchmark Design

Turn-based interaction with terminal hidden-intent tracking

The simulated user tracks hidden intents throughout the interaction. Agents receive only normal user-facing messages, while evaluators score whether each intent was completed, inferred by the agent, or merely provided by the user.

Build personal episodes

Each user domain combines a profile, workspace files, app state, prior history, tasks, hidden intents, tools, and skills.

Run agents in persistent workspaces

Agents interact with files, apps, and the simulated user across multiple turns, rather than solving isolated prompt-only questions.

Evaluate proactivity and completion

Proc is computed from hidden-intent coverage; Comp is computed from rubric and rule graders over the final trajectory and artifacts.

Run

Reproduce benchmark runs

Full benchmark runs require Docker or Podman, provider credentials, Brave Search credentials, and the prebuilt localhost/bench:v1 image.

Install minimal dependencies

pip install -r src/requirements.txt

Run package entry

python -m src.main \
  --config config/bench/nanobot.yaml \
  --history-config-path config/bench/evaluation/trace_history.yaml

Run one Docker job

bash scripts/run_parallel_models_docker.sh \
  --user-id law_trainee \
  --model-id MiniMax-M2.5

Start local test channel

python scripts/test_server.py
