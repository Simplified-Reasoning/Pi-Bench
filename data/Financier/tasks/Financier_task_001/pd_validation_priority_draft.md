# Draft PD Validation Priorities

This draft is intentionally weak.

1. Start with logistic-regression equations and coefficient significance.
2. List every variable in the model.
3. Compute AUC and KS.
4. Check whether the model has a nice scorecard format.
5. Mention monitoring at the end if there is time.

Draft problem:
- It is too formula-first.
- It does not say which issues could block model use.
- It does not connect the review to independent validation or SR 11-7.
- It does not distinguish high-risk red flags from routine statistical review.
