# Draft VaR Backtesting Priorities

This draft is intentionally weak.

1. Explain the VaR formula.
2. Define quantiles.
3. Show how historical simulation sorts returns.
4. Count the number of exceptions.
5. Mention Basel traffic-light colors.

Draft problems:

- It treats exception count as the whole review.

- It does not discuss P&L definition, exception clustering, volatility-regime behavior, or whether the model can continue to be used.
