# Web Browsing

Use this skill for source-grounded web inspection.

## When to use

- The task requires current or authoritative public information.
- The user needs product, treatment, or benchmark pages checked directly.
- A literature answer also needs supporting organization or product webpages.

## Workflow

1. Prefer primary sources such as journals, official product pages, regulators, or major clinical institutions.
2. Open the source page before summarizing.
3. Keep the answer tied to what the page actually supports.
4. Separate sourced facts from inference.
5. Preserve the URL or source identity in the final answer.
