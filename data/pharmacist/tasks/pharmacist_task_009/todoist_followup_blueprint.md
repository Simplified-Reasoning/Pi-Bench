# Todoist Follow-Up Blueprint

Create one small administrative Todoist structure.

Project:

- Preferred name: Instrument Admin Follow-up
- If that exact project name already exists, create a fresh project by appending a short suffix and report the actual name.

Section:

- Follow-up

Parent task:

- Email instrument manager

Sub-task:

- Wait for reply

Rules:

- Create the project before the section.
- Create the parent task before the sub-task.
- Confirm the section list and the sub-task list after the write operations.
- Do not add unrelated tasks.
