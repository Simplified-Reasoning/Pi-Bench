# API Property Summary

- API code name: API-X
- Target delivery site: superficial skin layers and shallow dermis
- Appearance: off-white powder
- Water solubility: very low, about < 0.05 mg/mL
- Solubility in ethanol: moderate
- Solubility in propylene glycol: relatively good
- Estimated logP: 3.1
- pKa: weakly basic, about 8.4
- Known issues: precipitation risk after standing; high ethanol ratio raises irritation concerns
- Initial constraints: the goal is a gel dosage form; the system should not be too irritating; the next step should compare 2-3 candidate formulation routes
- Additional practical tension: strong neutralization or an aggressive solvent push may improve one part of the system while making pH control, feel, or precipitation behavior harder to manage together

Still to be confirmed:

- Long-term stability
- Exact dose requirement
- Target release rate
- Whether a film-forming function is needed
- How narrow or wide the acceptable pH window really is once the gel base is fixed
