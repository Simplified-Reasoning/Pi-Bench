# Draft Fragments of Candidate Formulation Routes

- Possible direction 1: a carbomer-based baseline gel route
  - Note: gel formation is straightforward, but the balance between cosolubilization and precipitation still needs to be judged separately
  - Note: pH handling and gel-formation behavior will need to be watched separately in this route

- Possible direction 2: a lower-irritation co-solvent route
  - Note: this may better fit the preference for a milder system, but that does not automatically mean it solves API uniformity
  - Note: if the solvent push is too conservative, precipitation or poor uniformity may reappear before the screen even reaches stability testing

- Possible direction 3: an alternative-gel-base route
  - Note: it can be kept as a later comparison idea, but the current information is not enough to decide its priority directly
  - Note: it may be attractive if carbomer handling becomes limiting, but introducing a different base too early may blur whether the real first-round issue is solubilization or polymer choice

- This file intentionally does not provide a ready-made ranking
- Relative priority must be judged by combining API properties, benchmark borrowing points, and project preferences
