# Supply and Procurement Notes

- Basic excipients such as Carbomer 940, propylene glycol, glycerin, EDTA, and citric acid can usually arrive within the week and are suitable for first-round immediate purchase.
- Hydroxyethyl Cellulose can be bought in a small amount as an alternative gel-base route, but if the first round is clearly centered on the carbomer route, it can also be postponed.
- The preservative system is not fully fixed yet, so Phenoxyethanol can be listed as buyable but still needs compatibility confirmation.
- Packaging materials should not be purchased heavily at the beginning:
  - if this is only for a lab-scale pilot, basic aliquot containers are enough at first
  - if more stable presentation samples are needed later, then an airless pump can be considered
- Some online platforms sell packaging in very wide quantity ranges, so the first round should favor small or medium packs to avoid waste if the route later changes.
