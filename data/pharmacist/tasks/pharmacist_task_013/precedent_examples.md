# PROTAC Linker Precedent Fragments

This file only provides several precedent-style direction tags to remind the user that linker design involves more than length alone. It does not provide a final priority order.

- PEG-like flexible linker
  - Hint: often used as a conservative comparison direction
  - Hint: easy to anchor discussion, but may add polarity and sometimes make the design feel less differentiated

- alkyl / semi-rigid linker
  - Hint: may influence exposure and overall conformation
  - Hint: can be attractive when trying to shift geometry without exploding synthesis complexity

- cleavable linker concept
  - Hint: the mechanism and validation chain become more complex
  - Hint: promising on paper, but early-stage interpretation becomes harder because the linker itself adds another mechanistic layer

- branched / constrained linker
  - Hint: spatial geometry may become more sensitive and the chemistry is usually more complex
  - Hint: may create a stronger innovation story, but usually at the price of a more fragile first-round synthesis and validation plan

- This file intentionally does not expand every advantage and drawback
- Which options should be tried first and which should wait for a second stage must be narrowed down by combining these fragments with the project constraints and goal
