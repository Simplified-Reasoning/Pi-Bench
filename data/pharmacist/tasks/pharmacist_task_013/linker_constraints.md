# Current Linker-Design Constraints

## Project Stage

- The project is still in an early proof-of-concept stage.
- The higher priority is to narrow down 1-2 routes that are synthesizable, testable, and interpretable, rather than opening the design space too widely at once.

## Current Constraints

- The first round should not immediately introduce too many difficult-to-synthesize rigid motifs.
- The linker plan should preserve one low-risk comparator version so that it can be compared with familiar routes.
- If a route clearly adds substantial polarity, molecular weight, or synthesis steps, that cost should be flagged explicitly.
- The discussion should not collapse into linker length only, but it also should not expand into an execution-infeasible 'unlimited innovation' list.
- If a direction would require a longer validation chain before it can even be interpreted, that burden should count against first-round priority.

## Output Preference

- The end result should ideally land on 1-2 starting routes that are better suited for trying first.
- For each recommendation, the user wants to see the potential benefit, the main cost, and why it deserves priority.
